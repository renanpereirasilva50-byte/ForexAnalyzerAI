# Forex Analyzer AI — projeto Android

Aplicativo Android educativo em Kotlin + Jetpack Compose.

## Abrir
1. Instale o Android Studio.
2. Abra a pasta `ForexAnalyzerAI` (não apenas o arquivo Kotlin).
3. Aguarde o Gradle sincronizar.
4. Execute em um emulador ou aparelho Android.

## O que está incluído
- Pares EUR/USD, GBP/USD, USD/JPY e AUD/USD.
- Períodos M5, M15, M30, H1 e H4 (apenas rótulos da simulação).
- Gráfico de velas gerado com dados fictícios.
- Cálculo local de EMA 9, EMA 21, RSI 14 e MACD.
- Interpretação visual educativa e botão para gerar outra simulação.

## Limitações importantes
O app NÃO usa cotações ao vivo, não está conectado a corretoras e não envia ordens.
Os valores são aleatórios e não devem ser usados para decisões financeiras.
Para dados reais, seria necessário escolher um provedor de dados Forex, revisar os termos
de uso e implementar uma integração segura. Nunca coloque chaves privadas dentro do app.
